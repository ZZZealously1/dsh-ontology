# 领域本体说明入口

生成到 `ontology/docs/<domain>_本体说明.md`。复制并填写[完整领域说明模板](../skills/ontology-builder/references/full-domain-document.md)，统一使用其七章结构：概述、类定义、属性定义、规则详解、使用指南、验证报告、附录。覆盖本次范围内所有类、属性和规则的中文说明，表格可合并重复内容，但不能省略实际定义与字段含义。

本入口补充项目记录的交接关系，不另维护第二份完整模板：

| 说明位置 | 关联记录与补充字段 |
|---|---|
| 概述与架构 | 项目设计中的方法、适用范围、阶段产物、适配理由、领域维护责任、来源基线；统计声明图范围、去重方法和实际命令 |
| 概念与属性 | 业务身份、粒度和时间，原始/派生角色，来源及字段映射、SHACL约束和实例的对应关系 |
| 规则详解 | 唯一原生规则IRI与位置、条件阅读视图、例外和人工口径、后端支持及独立案例；不得另建平行政策 |
| 结构化公式（适用时） | 唯一RDF表达树位置、原LaTeX显示、符号/单位/输出、必要条件、依赖与来源；候选/激活状态和逐式独立算例，见[公式合同](../Ontology-tools/FORMULA.md) |
| 数据与使用 | ABox来源、快照时间、provided/synthetic标记、字段及关系证据、映射实现状态；命令注明工作目录，查询注明所读图 |
| 验收与附录 | 引用本版acceptance.md和日志，记录通过/总数、未完成项、版本变化、迁移/融合依据及可回退位置 |

完整模板中的示例只说明填写方式，未知项写未提供/未验证/不适用及理由；不为填满模板创造政策、标准符合性或运行结果。未知/人工预期通过不表示相关业务动作完成。

知识库素材按[RAG说明补充](rag-build/docs/doc_outline.md)增加检索覆盖与查询示例。其余格式和交付要求见[输出规范](../CONTRACT.md)。
