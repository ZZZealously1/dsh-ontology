# 标准文档建模

本技能提供标准文档的参考模型。**参考模型不代表已核验 GB/T 条款，也不对任意项目强制适用**。实际标准正文、版本和适用范围缺失时，把条款符合性标为待核验；不将参考模型中的示例阈值、唯一发布机构等假设转成真实业务约束。

1. 核对标准正文及项目问题，按[建模原则](../../references/modeling-principles.md)确定范围。把内容语义、文档结构、表述形式分开；同义概念先对齐，不因出现章节不同而重复建类。
2. 读取[完整参考模型](references/standard-document-model.md)：保留全实体目录、34 项对象属性、19 行数据属性、专门规则及扩展要求；逐项标记采用、调整、不适用或待确认。目录树不直接等于 OWL 继承树。
3. 选定身份、关系方向、属性的域和值域及真实约束。表中斜杠表示候选并集，不得用多个 domain/range 误写成交集。OWL 公理与 SHACL 数据检查分开，唯一键、功能性和开放世界语义按参考说明处理。
4. 从[原生资产说明](references/assets-and-validation.md)选择模板。模板是合成参考，采用前替换项目 IRI 并确认假设；生成至项目 `ontology/`，按[交付规范](../../CONTRACT.md)分开 TBox、SWRL 和 ABox。
5. 对照完整参考模型末尾逐条核验清单，执行 RDF 解析、[OWL DL 检查](../../Ontology-tools/OWL-DL.md)、SHACL 及独立案例；记录实际后端与未执行项。日期、引用、替代关系等来源缺口保持待确认，不补造结论。
