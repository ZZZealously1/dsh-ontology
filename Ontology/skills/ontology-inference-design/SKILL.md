# 规则设计与实现

本技能贯通业务规则设计、原生表达、查询和后端交接；适用于新增或修改推理能力、计算、分类、约束、时序判断及异常排查。遵守[公共原则](../../common_rules.md)和[输出规范](../../CONTRACT.md)。具体运行使用[执行方法](../ontology-execution/SKILL.md)，整包验收使用[验证与验收](../ontology-validation/SKILL.md)。

## 工作流程

1. **固定问题与依据。** 确定能力问题、对象身份和粒度、领域、快照/时间范围、来源条款、输入与结果含义；核对例外、未知、冲突和已确认的人工处置。阈值、精度、优先级、审批缺依据时保持未决，不补默认值。
2. **设计并回译。** 按[设计手册](references/inference-workflow.md)识别五类规则，逐项列出前提、关系连接、变量、合取与结论，再回译核对来源。计算须核对公式、量纲、定义域、类型、舍入与尾差；示例公式和阈值不是项目政策。
3. **选择表达并实现。** 按[实现与查询流程](references/implementation.md)及[推理模式](references/inference-patterns.md)选择下表机制；用[原生表达模式](references/swrl-sparql-patterns.md)编写规则与查询。记录所属领域、共享术语和跨域身份连接；未决候选与实际加载规则隔离，状态注释本身不能禁用规则。
4. **先定预期，再运行。** 按[规则设计与独立测试](references/rule-design-and-tests.md)构造正向、反向、边界、缺失及组合案例，分别验证单规则与整包行为。交接原生模型、规则、显式ABox、形状、查询、来源映射和独立预期，由实际兼容后端执行。
5. **比较并交付证据。** 核对完整目标结果集合、类型、关键中间事实和禁止结果；负例先证实运行正常完成。每个能力问题关联公理/规则/查询、来源与案例，保留加载范围、输入、产物、差异和复跑命令；设计通过与执行通过分别报告。

| 所需能力 | 表达与关键边界 |
|---|---|
| 类别、身份或关系的逻辑后果 | OWL公理；核对实际后端支持的构造、分类和一致性能力 |
| 多项事实共同成立时增加断言 | SWRL；核对原子、变量绑定、数据类型、内建签名与规则组合 |
| 结构化科学/工程公式求值 | [RDF表达树与公式配置](../../Ontology-tools/FORMULA.md)；原生目录为唯一公式执行源，诊断与适用性由OWL/SWRL表达 |
| 输入完整性或结果形状 | SHACL；明确原始/推导/闭包图及前后校验阶段 |
| 筛选、关系路径或读取结果 | SPARQL；记录参数、查询图、对象/时间范围、零跳与重复处理 |
| 聚合、舍入、优先级或状态变化 | 有来源的应用执行契约及兼容实现；不能默认普通SWRL提供 |

## 执行边界与完成条件

- SWRL条件是合取，书写顺序不是业务优先级；head不能自动撤回断言、覆盖状态或执行动作。递归、计算绑定、新个体生成和时序行为按实际后端核验，推导候选不表示审批或业务动作已完成。
- 本库[计算配置](../../Ontology-tools/CALCULATION.md)可执行明确子集的四则、显式舍入与带时区的基础时间运算。函数输入先绑定、输出可供后续计算；审查精确 IRI、类型、单位、非终止除法、舍入来源及毫秒范围。候选仅由成功规则头扩张，生成依赖环保守拒绝；日期工作视图的 UTC 转换须有映射证据，不能据工具函数替项目补业务口径。
- 新[公式配置](../../Ontology-tools/FORMULA.md)直接读取静态RDF表达树，不要求逐公式改写为SWRL运算链。逐式核对符号、量纲、必要条件和来源，参数绑定同一对象/工况；条件未知不当作成立。成功完整求值后才发布结果，目录抽取候选、失败中间值和语言手算均不激活。激活公式全部独立验算，公式覆盖不并入SWRL规则覆盖。
- SPARQL的否定与聚合针对指定图；未确认集合完整性时，不解释为业务否定或完整总量。缺值、无匹配、多规则命中、冲突、人工事项和技术错误分别表达。
- 后端不支持时保留原语义并选择兼容实现或标记未执行，不能删条件换取通过。OWL一致性检查、语法解析或大模型阅读均不证明SWRL已执行；语法与内建词汇见[OWL/SWRL参考](../../references/owl-swrl/index.md)，实际支持以选用后端为准。
- 所有适用规则须有单元测试设计；实际执行覆盖按[验收清单](../ontology-validation/references/acceptance-checklist.md#覆盖记录)统计，至少80%，未覆盖项保留。该门槛不能豁免失败或替代边界、组合和能力问题验证。
- 推理任务须实际产生与能力问题对应的非空推导，纯查询按独立预期验收；未运行记录 `not_run`，自然语言解释不充当确定性执行记录。
