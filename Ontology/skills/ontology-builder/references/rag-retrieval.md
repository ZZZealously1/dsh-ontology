# 知识库检索操作与参数核对

先区分现场可用 API 与用户已提供的检索快照。当前方法不附带或自动调用远程连接器；仅有工具名称不证明已安装、凭据可用或检索已完成。

## 取材流程

1. 明确知识库身份、业务范围、资料有效期与用户授权。使用平台实际提供的知识库列表与检索接口，核对索引标识。例如，采用阿里百炼连接器时可核对 `BailianKnowledgeBaseList`、`BailianKnowledgeBaseRetrieve` 及 `IndexId` 的实际契约；这些名称不构成已安装接口的声明。若有多个候选知识库，用名称、描述、文档清单核对，不凭相似名字选库。
2. 完成列表分页，记录实际分页参数、返回数量和终止条件。扩大单页不等于已经遍历全部页；以现场接口的分页字段、上限和下一页标识为准。
3. 每轮围绕一个主题：组织架构、业务分类、系统架构、权限体系、业务流程、性能参数；按领域增减。中文自然语言可并列多个近义关键词。把业务问答拆成实体、谓词关系、数据字段和层级证据，不把召回摘要当完整制度。
4. 对每个片段记录知识库/索引标识、查询文本、参数、命中顺序与得分（如可得）、文档 ID/名称/版本、页码或章节、片段 ID、引用原文、提取结论、是否待确认。检索日志与来源快照放项目 `ontology/provenance.ttl` 或文档/表格，不生成 JSON。
5. 跨主题合并同义词及指代；冲突保留双方来源与优先级待确认。无结果只表示本轮未命中，不能推出事实不存在。参数、别名或措辞调整后记录新轮次，不能删除失败检索痕迹。

## 参数与故障核对

| 字段或现象 | 核对与处理 |
|---|---|
| 知识库列表与分页 | 核对索引标识、字段名称、最大页大小、可见权限与结束条件，不能只查首页 |
| `DenseSimilarityTopK` / `SparseSimilarityTopK` | 按现场 schema 核对稠密/稀疏召回数量的取值范围和默认值；参数名与限制不视为所有平台通则 |
| `RerankTopN` | 明确进入上下文的重排结果数量；截断结果不证明证据覆盖完整 |
| 中文查询 | 可并列同义关键词；保留原查询和改写，比较召回证据而非仅看回答 |
| `query is empty` | 先核对请求是否实际含非空文本及字段映射；修正参数或措辞后有限重试，并保留错误记录 |
| 大结果 | 保存结果并分片或委派抽取；保持文档定位、片段范围与覆盖清单，避免截断后声称通读 |
| 抽取规模 | 实体、关系、属性和类层次数量由材料与能力问题决定，不为达到预设数量发明模型 |
| 环境准备 | 核对已具备的运行环境与依赖，连接或安装遵守当前授权；本地工具依赖见[锁定清单](../../../Ontology-tools/requirements.lock.txt)，模板测试使用标准库 `unittest` |

在仅授权本地建模时，接收已有 TXT/Markdown/CSV/RDF 检索快照后从步骤 4 继续。缺少原始制度的关键阈值、审批口径或互斥断言必须记录为缺口，不能用平台默认参数补成业务政策。
